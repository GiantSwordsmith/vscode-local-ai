# vscode-local-ai

Offline AI assistant for VS Code. No internet. No API keys. No cloud.

---

## What it does

Adds AI code assistance to VS Code.  
Select code → press shortcut → get suggestion.  
Everything runs locally on your CPU.

---

## Setup

1. Download the archive from Releases  
2. Open `localai.exe`  
3. Restart VS Code  
4. Select code and press `Ctrl+Shift+A`

---

## What works

- Explain what code does  
- Suggest simple fixes  
- Add comments  
- Basic refactoring  

Small model. Simple tasks. Fast enough.

---

## Requirements

- Windows 10 or 11  
- VS Code 1.85 or newer  
- 2 GB RAM  
- Any CPU from last 5–6 years  

---

## Why

Some people work offline.  
Some don't trust cloud APIs.  
Some just want things to run locally.  

This is for them.
